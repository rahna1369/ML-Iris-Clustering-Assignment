# ML-Iris-Clustering-Assignment
KMeans and Hierarchical Clustering analysis on the Iris dataset for machine learning assessment

## Project Overview
This project demonstrates two types of unsupervised machine learning:
* *K-Means Clustering* (to group flowers by centroids)
* *Hierarchical Clustering* (using a Dendrogram)

## Dataset
The project uses the classic *Iris dataset* from sklearn.datasets.

## Tools Used
* Python
* Pandas
* Scikit-Learn
* Matplotlib & Seaborn
